# Pipeline

Copy this whole folder into the project as `video/`:

```bash
cp -R .claude/skills/launch-video/scripts video && cd video/render && npm i
```

```
stage/index.html   the animated stage — window.seek(t) renders frame t (edit this per project)
stage/assets/      fonts (shipped) + your frame sequences: mont/, hf/, isaac/, avatar/ …
stage/timing.js    generated by audio/compute-timing.mjs — do not edit
stage/subs.js      generated by audio/subs.mjs — do not edit
render/render.mjs  headless Chrome -> PNG frames (and --stills)
audio/eleven.mjs   narration segments + music (ElevenLabs)
audio/beats.mjs    BPM + phase from the generated music
audio/compute-timing.mjs  VO durations + beats -> out/timing.json, vo-starts.json, stage/timing.js
audio/subs.mjs     forced alignment -> out/*.srt + stage/subs.js
audio/assemble.mjs frames + placed VO + ducked music -> out/*.mp4
audio/avatar.mjs   optional lip-synced avatar hook (ElevenCreative Flows)
out/               frames/, stills/, timing.json, the mp4 (gitignore this)
```

The stage template is the shipped Kite Evals v2 cut. Keep its structure (helpers, camera model,
subtitle layer, `window.*` globals); replace the scenes, copy, and assets.

`render.mjs` and `assemble.mjs` take `--stage`, `--frames`, `--stills-dir`, `--out` so you can
render variants side by side without clobbering each other.
